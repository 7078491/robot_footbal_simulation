机器人足球仿真模拟

这是一时心血来潮 看完几场浙江机器人足球比赛的产物
比赛中的机器人选手基本上很难看出有什么有效的配合
由此得到了本项目的灵感

本项目的目标旨在通过对机器人足球战术的优化设计实现比赛中的战术优势
进而获取比赛的胜利

本项目以python为主要技术栈，应用了规则库结构
我们通过双方机器人到球的距离和相互位置关系定义了有利区等区域的核心概念，
原则上我们需要设法在比赛中通过抓对手阵型的空当从而形成有威胁的进攻

为了指导机器人球员采取符合预期的行动，设计了整个队伍的规则体系
我们有基础规则和策略规则两大类，当机器人遇到特定情况时，它根据条件判断应该执行什么动作
这些动作是预先定义好的
